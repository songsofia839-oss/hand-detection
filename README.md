## Overview

### The Function
Backend: able to receive images from user's camera, detect and connect fingers with dots and lines, analyse dot points to determine numbers 1 to 5 shown by hand. 
Frontend: Have a webpage with pages "Home" and "Try-it", displayed the functions and guidelines of how to play with the hand detection tool
